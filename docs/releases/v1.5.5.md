BetterClaude 1.5.5 shows your plan limits and context window in the Code tab at a glance, and how long Claude has been working.

## Code tab

- **Usage rings in the message box.** Three small rings next to the model picker show your **session limit**, **weekly limit** and this conversation's **context window**, filled in as percentages. Click them for a dropdown with bars, reset times ("resets in 4h 16m · 3:40 AM"), tokens used of the window, and a **Full context breakdown** (system prompt, tools, skills, memory, messages, free space), the same numbers as Claude Code's `/context`.
- **The sidebar circle finally fills.** It used to stay empty until Claude Code happened to report a limit mid-chat. It now shows your real session and weekly usage from the moment the app opens, and refreshes after every reply and every few minutes. The numbers come from Claude Code's own `/usage` data. Nothing is sent to Claude and nothing counts against your plan.
- **How long Claude has worked.** A live timer runs at the bottom of each turn while Claude works ("Working · 1m 12s"), and every reply's footer says how long it took ("worked 1m 12s").

## Downloads

Update with the one-line installer (no security prompts):

```bash
curl -fsSL https://raw.githubusercontent.com/ara-mkr/betterclaude/main/scripts/install.sh | bash
```

```powershell
irm https://raw.githubusercontent.com/ara-mkr/betterclaude/main/scripts/install.ps1 | iex
```
