BetterClaude 1.5.1 is a polish release for the Code tab. Signing in is one click, the model menu tells you exactly which model you're on, the usage card shows your real Claude Code numbers, and the logo now follows your theme.

## What's new

- **One-click sign in.** If Claude Code's login to your Claude account is missing or has expired, the Code tab says so in plain words and offers **Sign in to Claude**. It runs Claude Code's own sign-in (`claude auth login --claudeai`) in the Terminal panel and opens your browser. That is your Claude subscription, never an API key. Your message stays in the box, so you just send it again.
- **Real model names.** The model menu and the dock's model widget say **Opus 5.5**, **Sonnet 5.5**, **Haiku 4.5** and **Fable 5.1**, not just "Opus". **Default** now names the model it really is, for example **Default · Opus 5.5**. BetterClaude asks Claude Code directly when the Code tab opens and whenever you switch projects, before you send anything. Nothing is billed for it.
- **Your plan usage, both windows.** The usage popover shows your 5-hour window and your weekly limit side by side, each with when it resets, straight from what Claude Code reports while you chat. The dock widget and the VS Code status bar read the same numbers.
- **Claude Code usage stats.** A new session opens on Claude Code's own `/stats` card: sessions, messages, total tokens, active days, peak hour, favourite model, a day heatmap and a per-model breakdown, for All, 30 days or 7 days.
- **The logo matches your theme.** The mark in the top-right corner takes your theme's accent colour and adjusts it so it always stands out from the title bar. It's green on Matcha, frost blue on Nord, and white on the mono themes.
- **Every theme gets its own accent back.** Picking a theme now uses that theme's own accent colour instead of BetterClaude Default's indigo.
- **Brutalist Mono is actually mono.** The vibe now uses Mono Black, so hover and focus rings are bright white instead of yellow.

## Removed

- The old Usage Analytics dashboard (Settings, Cmd-K and its local database). Claude Code's own stats card replaces it.

## First launch

**macOS:** the builds are ad-hoc signed but not notarized (notarization needs Apple's paid Developer Program), so the first open of a downloaded copy shows *"BetterClaude not opened. Apple could not verify it."* That's Gatekeeper, not a broken file. Here's the one-time way past it:

1. Drag BetterClaude to `/Applications`, try to open it, and click **Done** on the dialog (don't move it to the trash).
2. Open **System Settings, Privacy & Security**, scroll to the Security section, and click **Open Anyway** next to the BetterClaude message. Authenticate, then click **Open**.
3. It opens normally from then on.

Terminal alternative: `xattr -cr /Applications/BetterClaude.app`

**Windows:** SmartScreen shows *"Windows protected your PC"* because the installer isn't signed by a recognized publisher yet. Click **More info**, then **Run anyway**. Windows updates in place from each new release. On macOS, download each new DMG by hand until the build gets a Developer ID certificate and notarization.
