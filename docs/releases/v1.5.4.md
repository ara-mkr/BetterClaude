BetterClaude 1.5.4 lets you queue messages in the Code tab and makes permission-mode changes apply right away.

## Code tab

- **Queue messages while Claude works.** Type and press Enter while Claude is busy, and your message is queued above the message box instead of refused. Queued messages go out in order as each turn finishes. Each one has **Send now** (stops the current turn and sends it immediately), **Edit** (moves it back into the message box) and **Remove**. If a turn ends in an error, the queue pauses until you press Send now.
- **Mode changes apply immediately.** Switching to Auto, Accept edits or Bypass mid-turn used to take effect only from your next message, so Claude kept asking for permission. The running turn now switches on the spot. Approval cards already open that the new mode wouldn't have asked about are answered for you: everything under Bypass, file edits under Accept edits. Questions and plan approvals still wait for you.
- **Auto says when it can't run.** Claude Code has no Auto mode for Haiku 4.5. The mode menu now says so and points you to another model, instead of quietly falling back to asking.


```powershell
irm https://raw.githubusercontent.com/ara-mkr/betterclaude/main/scripts/install.ps1 | iex
```
