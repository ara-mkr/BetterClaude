BetterClaude 1.5 is the update that makes the Code tab feel like a proper IDE. It now looks and works like Claude Code desktop, there is an optional full VS Code beside the chat, the Live Wire shows what your agents are doing much better, and every screen shares one consistent look.

![BetterClaude 1.5](https://raw.githubusercontent.com/ara-mkr/BetterClaude/main/.github/readme-assets/v1.5-hero.png)

## What's new

- **A Code tab that works like Claude Code desktop.** Projects and sessions on the left, one conversation in the middle, and Changes, Files and Terminal when you want them.
- **A real IDE when you want one.** Flip a switch and VS Code sits beside the chat, with your extensions, your theme and Commit & PR.
- **A better Live Wire.** Every message and hand-off in the order it really happened, with tags you can scan, and agents with plain names you can change.
- **One consistent look.** Chat, Code, CLI, Settings and the widgets all follow the same theme now, whichever theme you pick.
- **12 new widgets,** a new icon, and a sign in page you can click.

## A Code tab that works like Claude Code desktop

![The Code tab](https://raw.githubusercontent.com/ara-mkr/BetterClaude/main/.github/readme-assets/v1.5-code.png)

Open Code and you land in the conversation, the way you do in Claude Code desktop. Your projects and their sessions sit in the sidebar. Click an old session and its whole transcript loads. Several sessions can run side by side, each streaming its own reply.

- **Each tab is a real Claude Code session,** not a lookalike. Commands, questions and plans show up as cards you answer in the app.
- **Four modes:** Ask, Accept edits, Plan and Auto. Stop stops. Background tasks report back and start their own follow-up turn.
- **The side panel comes and goes.** Changes shows the diff and a **Commit & PR** button, Files browses the project, and Terminal gives you a shell in the folder.
- **The composer is quick.** Enter sends, `/` opens the slash menu, drafts are kept per tab, and a mic button dictates locally on macOS.
- **You always see where you stand.** A usage ring in the sidebar, a per-reply token line, and a model menu for Opus, Sonnet, Haiku and free models.
- **It runs on your Claude plan.** If a settings file would send the chat to an API key or another provider, BetterClaude stops before sending anything and tells you why.

## A real IDE, when you want one

![VS Code inside the Code tab](https://raw.githubusercontent.com/ara-mkr/BetterClaude/main/.github/readme-assets/v1.5-ide.png)

Flip the layout (Cmd-Opt-I) and the Code tab becomes a real VS Code workbench with the chat beside it. It is optional. Nothing downloads until you say so, and the size and source are shown first.

- Install extensions from Open VSX, import the ones you already have from VS Code, Cursor or Antigravity, or drop in a `.vsix`.
- Your theme and code font follow BetterClaude. Open a file or a diff straight from the chat, send a selection to the chat with Cmd-Opt-L, and use Commit & PR from Source Control.
- It all stays on your machine. The engine listens on 127.0.0.1 only, its token never shows up in a URL or a log, and it stops itself after ten idle minutes.

## A better Live Wire

![The Agent team panel and the Live Wire](https://raw.githubusercontent.com/ara-mkr/BetterClaude/main/.github/readme-assets/v1.5-team.png)

The Live Wire is the rail where you watch your agents work together. It now shows every message and hand-off in the order it really happened, even when an agent stamps a made-up time on it. Review, done, question and handoff tags are easy to scan, and a long sender name no longer squeezes the recipient down to one letter.

Teammates used to arrive with codenames like Atlas and Nova. Now they are Agent 001, Agent 002 and Agent 003, handed out in order. If you would rather have Backend and Reviewer, double-click a name or press **Rename** on its card. Its work, its history and its messages stay put, and the old name keeps working for any agent that still signs with it.

**How a message reaches an agent**

- It is typed into a teammate only when Claude Code itself says that session is idle at its prompt. Never into a permission prompt, never on top of text you are typing.
- Messages from before the app started are never replayed. A busy or offline teammate gets its messages queued, not lost.
- Agents can't flood each other. There is a per-agent rate limit, a pause after a long back-and-forth, and duplicates are dropped. Your own messages skip all of that.
- Message text is stripped of control characters, and agents are told that a teammate can't approve anything for them.

**Code tab chats can join a team too** (More, then Join the agent team). A teammate's message follows that chat's own mode. In Ask mode, an edit a teammate asks for raises the same approval card as anything else, and if you change the mode chip after joining, the next teammate turn follows it. Before this release a chat kept the mode it had when it joined, so tightening to Ask later could still let a teammate's edit through. That is fixed.

## One consistent look

![The theme picker](https://raw.githubusercontent.com/ara-mkr/BetterClaude/main/.github/readme-assets/v1.5-themes.png)

Chat, Code, the CLI tab, Settings and the widgets now draw from the same set of colors and sizes, so picking a theme changes all of them together, light or dark.

- **Theme resets no longer bleed into BetterClaude's own panels.** The Team sidebar, widgets and Quick Prompts follow every theme instead of picking up the page's colors.
- **The Code tab keeps its type scale** under every theme. It used to be flattened to a single size.
- **The composer** no longer shows a hard-cornered box inside its rounded card, and the send button is one clean fill.
- **Settings** opens centered with an even margin. In the CLI pane it used to sit low with a dead strip above it.
- **Density:** Spacious now actually spaces things out.
- Every theme was regenerated.

## 12 new widgets

![The widget gallery in Settings](https://raw.githubusercontent.com/ara-mkr/BetterClaude/main/.github/readme-assets/v1.5-widgets.png)

Settings, then Widgets. They are all off by default, and each one adds a small button to the dock.

| Widget | What it does |
| --- | --- |
| Plan Usage | How much of your plan's current window is used |
| Context Gauge | How full the Code tab chat's context window is |
| Git Status | Branch, changed files and unpushed commits |
| Team Mini-Wire | The last few team messages, without opening the CLI tab |
| Session Timer | Time in this conversation, with an optional break nudge |
| Focus Mode | Hide everything but the conversation |
| Daily Streak | Days in a row you've used Claude |
| Shortcut Cheat Sheet | Every BetterClaude, Code tab and Claude Code shortcut |
| Clipboard History | Your last 20 copies on this page, kept in memory only |
| System Monitor | Machine load, memory and BetterClaude's own use |
| Model Switcher | Pick the Code tab's model from the dock |
| Scratchpad | One big plain-text pad that survives restarts |

Plan Usage reads the number Claude Code reports with each reply. Nothing is scraped, stored or sent anywhere. Cards open just below the dock instead of on top of it, and the dock wraps instead of running into the page.

## A sign in page you can click

![The sign in page, readable again](https://raw.githubusercontent.com/ara-mkr/BetterClaude/main/.github/readme-assets/v1.5-signin.png)

If you opened Chat while signed out, you could land on a page with a video playing and no buttons you could see or click. The app was forcing the page into a window-high box, which pushed the form above the top edge, and some themes painted a button's label in the same color as its fill. Now the form sits where you can reach it, each label is picked from the color the button is actually painted with, and your widgets stay out of the way. If you see this page inside BetterClaude, you are signed out of claude.ai, so sign in once and you're back.

## The small stuff

- **A new icon** in liquid glass, and a white-mark-only glyph in the menu bar that adapts to light and dark.
- **CLI tab:** a new "Load my ~/.claude settings in CLI tabs" setting, on by default like your terminal. Turn it off to keep the tabs on your plan. Escape closes the Team sidebar, the Live Wire and the Sessions picker.
- Ollama answers now stream, so a long answer is no longer cut off at 60 seconds.
- A chat that joins a team no longer gets the title "Empty Conversation Start", and session titles never show the delivery header.
- `settings:set` accepts writes only from BetterClaude's own windows.

## First launch

**macOS:** the builds are ad-hoc signed but not notarized (notarization needs Apple's paid Developer Program), so the first open of a downloaded copy shows *"BetterClaude not opened. Apple could not verify it."* That's Gatekeeper, not a broken file. One-time way past it:

1. Drag BetterClaude to `/Applications`, try to open it, and click **Done** on the dialog (don't move it to the trash).
2. Open **System Settings, Privacy & Security**, scroll to the Security section, and click **Open Anyway** next to the BetterClaude message. Authenticate, then click **Open**.
3. It opens normally from then on.

Terminal alternative: `xattr -cr /Applications/BetterClaude.app`

**Windows:** SmartScreen shows *"Windows protected your PC"* because the installer isn't signed by a recognized publisher yet. Click **More info**, then **Run anyway**. If your browser quarantines the download, choose **Keep** first. After install, Windows updates in place from each new release. On macOS, grab each new DMG by hand until the build gets a Developer ID certificate and notarization.

## Upgrading

- The built-in widgets update in place. A copy you edited yourself is left alone, as before.
- If you saved a Custom theme, it keeps the CSS it was saved with. Save it again to pick up the theme fixes.
