BetterClaude 1.5.6 fixes copying in the Code tab.

## Fixed

- **Copy buttons work.** The **Copy** button on code blocks (and **Copy diff**) did nothing: the Code tab's page isn't allowed to touch the clipboard directly, and the error was swallowed. Copying now goes through the app itself, says **Copied** when it works, and tells you if it ever doesn't.

## New

- **Copy a whole reply.** Every reply from Claude has a copy button at the start of its footer. It copies the reply as Claude wrote it, markdown and code blocks included.
