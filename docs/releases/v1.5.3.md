BetterClaude 1.5.3 makes installing painless, gives the Code tab images, and fixes its model picker.

## Install without the security prompts

New one-line installers download the latest release straight from GitHub and install it. That skips macOS's *"Apple could not verify BetterClaude"* trip to Privacy & Security and Windows' *"Windows protected your PC"* screen. Run the same command again any time to update.

**macOS** (Terminal):

```bash
curl -fsSL https://raw.githubusercontent.com/ara-mkr/betterclaude/main/scripts/install.sh | bash
```

**Windows** (PowerShell):

```powershell
irm https://raw.githubusercontent.com/ara-mkr/betterclaude/main/scripts/install.ps1 | iex
```

Why this works: browsers mark downloaded files as "from the internet", and that mark is what makes macOS and Windows question apps that aren't signed with a paid developer certificate. Files these commands fetch don't get the mark. Both scripts are short and readable: [install.sh](https://github.com/ara-mkr/BetterClaude/blob/main/scripts/install.sh), [install.ps1](https://github.com/ara-mkr/BetterClaude/blob/main/scripts/install.ps1).

The DMG window now also says how to get past the block if you install it by hand.

## Code tab

- **Images.** Drag images or files onto the chat, paste a screenshot with ⌘V, or use **+ → Attach files or images**. Images go to Claude as real images, not file paths. Big ones are shrunk to fit automatically. If you attach an image with no text, Claude is asked what's in it.
- **Attach from anywhere.** Attaching a file from outside the project (your Desktop, Downloads…) used to fail with *"Attachments must stay inside the selected project."* Now it just works.
- **The model picker shows the newest models.** It could show Opus 4.6 and Sonnet 4.6 instead of Opus 5.5 and Sonnet 5.5. It now lists the newest model of each family (Fable 5.1, Opus 5.5, Sonnet 5.5, Haiku 4.5), plus an **Older models** item that opens to the right with every earlier version your plan offers (Opus 4.8, Opus 4.6, Sonnet 4.6…), like Claude's own app.

## Installing by hand

**macOS:** the builds are ad-hoc signed but not notarized (that needs Apple's paid Developer Program), so a DMG from the browser shows *"BetterClaude not opened. Apple could not verify it."* Click **Done**, then go to **System Settings → Privacy & Security** and click **Open Anyway**. Or run `xattr -cr /Applications/BetterClaude.app` in Terminal.

**Windows:** on the SmartScreen prompt, click **More info**, then **Run anyway**.
